Collection and analysis rules

Visits use fresh contexts and run sequentially. The collection sequence is load, wait 10 seconds, handle consent, wait 5 seconds, scroll, wait 5 seconds and close. Ignore omits consent handling and its 5-second wait.

Analysis includes only HTTP requests receiving a response, including error responses. Domains use eTLD+1 and the final page URL determines first-partyness. Unknown entity mappings remain unknown.
